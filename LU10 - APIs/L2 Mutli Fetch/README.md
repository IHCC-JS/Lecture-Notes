# Cat API Example Day 3

This is a simple web application that allows users to select a cat breed from a dropdown list and fetch a random cat image for the selected breed using the Cat API.

## Prerequisites

Before getting started, you'll need the following:

- A Cat API key. You can get one by signing up on the [Cat API website](https://thecatapi.com/).


### Set Up Your API Key

Replace `YOUR_API_KEY` in the `script.js` file with your actual Cat API key.

> Warning since your API key is client side, it will not be hidden.
