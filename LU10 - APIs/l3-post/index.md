# L3 POST Building our own API

Today we will front scatch build our own API and consume it. 

## Backend

Today we will build our own API.
This API is built in [Express,](https://expressjs.com/) which is build on Node.js.

- [Video about Express](https://www.youtube.com/watch?v=-MTSQjw5DrM)

First build a folder called backend.
Then run the following. 

```bash
npm init
npm install express cors
```

Build out `server.js` file.
**Have students copy it**.
Run the server.

```bash
node server.js
```

Show off `.http` tests. Don't make students write them.
