# Intro to Events

[//]: # (TODO focus on other events other then click)

https://developer.mozilla.org/en-US/docs/Learn/JavaScript/Building_blocks/Events

1. Events are things that happen on your web page that your code can respond to.
2. For example:
    - The user selects, clicks, or hovers the cursor over a certain element.
    - The user chooses a key on the keyboard.
    - The user resizes or closes the browser window.
    - A web page finishes loading.
    - A form is submitted.
    - A video is played, paused, or ends.
    - An error occurs.
3. To react to an event, you attach an event handler to it. This is a block of code (usually a JavaScript function) that
   runs when the event fires.
4. There are a lot of different types of events. Your web browser (client-to-servers apps) can see everything you do.
    - https://developer.mozilla.org/en-US/docs/Web/Events
5. We can add events to any element
6. To do this we will use `.addEventListener()` function
