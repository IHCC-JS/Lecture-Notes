# Number Generator

[//]: # (This version of this project made example was made by: Devin Johnson)
[//]: # (TODO fix the styling and convert it to tailwind)

Purpose: Practice use of events on HTML DOM.

Build a form where the user enters the number of numbers they want the program to generate. 
After pressing enter the webpage generates a group of numbers each number should be color coded based on if it is even, odd, or prime. 
Add some validation where the user can’t enter a number above 100 and the input must be numeric.

## Requirements

1. Have most code executed based on an event.
2. Template must be generated.
3. Numbers must be color-coded.
4. User validation (1-100).
