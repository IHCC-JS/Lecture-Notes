## How to Run Marp

In a terminal, run the following commands to see the slides:

```bash
npm install 
npm run marp
```

Now right-click on `index.html` and select "Open in Browser" > "Build-in".

## Build Some JSON

In a `.json` file, Build the following structure:

```json
[
  {
    "name": "Spongebob",
    "age": 30,
    "isEmployed": true
  },
  {
    "name": "Patrick",
    "age": 34,
    "isEmployed": false
  },
  {
    "name": "Squidward",
    "age": 45,
    "isEmployed": true
  }
]
```

## Validate JSON

Now open the JSON file in your web browser to check if it's valid.
