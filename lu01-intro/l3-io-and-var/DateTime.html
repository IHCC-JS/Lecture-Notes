Date Time

Date Object

  • The built-in Date object stores a date and time value.
  • It is great for quick tasks like "what time is it right now?"
  • Common methods: new Date(), getFullYear(), toLocaleString().

Example: const now = new Date();

Temporal

  • Temporal is a newer date/time API designed to be clearer and safer than Date.
  • It separates concepts like date-only, time-only, and timezone-aware values.

Example: const today = Temporal.Now.plainDateISO();
