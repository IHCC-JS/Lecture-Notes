1. a function is a reusable block of code to perform a certain task.
2. A function can be declared or created in a couple of ways:
    - Declaration function
    - Expression function
    - Anonymous function
    - Arrow function
3. Now let's show all the different ways you can use a function, JS functions can only return one value unlike python
4. build `declFunction.JS`
5. Let's start to use arrow functions. Arrow functions were introduced in 2015 with the updates provided in ECMAScript
   2015, or ES6. They were added to clean up function expression syntax.
6. Arrow functions don't have binding to `this`, `args`, or `super`. So do NOT use them in methods (functions inside an
   object)
7. You can't use arrow functions to make a constructor.
    - https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Functions/Arrow_functions
8. Now let's play with arrow functions. build `arrow.js`
