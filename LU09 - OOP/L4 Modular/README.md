# L4 Modular

Today's very short lesson is about making module projects
To keep out code clean, we want a lot of our business logic in modules either in a separate file or in the class methods.

## Activity

Finish the example. 
Only need to code `script.js`

## In class exercise

Given students the project that is 90% done.
Have students finish the rest of the project in class.
Have it due midnight that night.
